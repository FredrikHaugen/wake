# wake CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macOS command, `wake`, that stops the Mac from sleeping, starting the screen saver or locking. It runs open-ended until stopped or the battery runs low, or for a set time (`wake 3m`, `wake 2h`, `wake 1h30m`), and shows a big countdown with a progress bar as wide as the terminal.

**Architecture:** A zero-dependency Node script written in TypeScript that Node runs directly (type stripping, no build). Keeping awake is delegated to macOS's own `caffeinate`, started as a child tied to wake's process id so it dies with wake. Pure modules (durations, battery parsing, drawing, frame layout) feed one loop, `run(argv, deps)`, whose side effects all arrive through an injected `Deps` object, so the loop is tested with a fake clock.

**Tech Stack:** Node 26 (any ≥ 24), TypeScript 7 for type checking only, `node:test`, macOS `caffeinate` and `pmset`.

**Spec:** No separate spec. The request, verbatim: "Create a simple cli script that has the command wake that prevents the mac to go to sleep or lock the screen, just using the wake command will keep everything awake indefently until it gets to low power, awake 3m, 3h, 3s and so on will have a timer, with a cool sort of timer and progressbar filling available space of your terminal". The interpretations this plan adds are under Global Constraints.

**Checked on this Mac on 2026-11-22:**
- `caffeinate -d -i -m -s -u -w <pid>` still held PreventUserIdleDisplaySleep, PreventUserIdleSystemSleep and PreventSystemSleep after 7 s, and exited on its own when `<pid>` exited. `-d -i -u -s` without `-t` is the flag set reported to stop the screen saver ([Ask Different 400737](https://apple.stackexchange.com/questions/400737/caffeinate-prevent-screensaver-catalina)); adding `-t` is what broke it there.
- Node 26.13.0: `node --test` finds `test/*.test.ts` with no flags, but on its own it also runs every other file under `test/` (such as `helpers.ts`), so the script passes the quoted glob `'test/*.test.ts'`. A `.js` entry with a shebang can import `../src/*.ts`, also when started through a symlink.
- `npm prefix -g` is `/opt/homebrew`, whose `bin` is on PATH; no `wake` or `awake` command exists yet. Latest `typescript` is 7.0.2.
- `script -q <file> <cmd> < /dev/null` gives the command a 0×0 pseudo-terminal and sends it a Ctrl-D (`\x04`) without hanging up.
- `pmset -g batt` prints `Now drawing from 'AC Power'` then ` -InternalBattery-0 (id=…)\t90%; AC attached; not charging present: true`. A Mac without a battery prints only the first line.

## Global Constraints

- macOS only. Node ≥ 24 runs `.ts` directly: no build step, no runtime dependencies. Dev dependencies are `typescript` and `@types/node`, nothing else.
- Erasable TypeScript only (no `enum`, `namespace`, parameter properties). Relative imports end in `.ts`; type-only imports use `import type`.
- The command is `wake`. The request's "awake 3m" is read as the same command.
- Keeping awake is exactly `caffeinate -d -i -m -s -u -w <wake's pid>`, never with `-t`.
- Low battery means running on battery power with charge ≤ 10% (`LOW_BATTERY_PERCENT = 10`). It applies to timed and open-ended runs; checked before starting and every 30 s.
- Durations: one or more `<number><unit>` parts, units `s m h d`, decimals allowed, case-insensitive, whitespace ignored. A bare number is rejected.
- The timer follows the wall clock (`Date.now()`), so time the Mac spends asleep counts.
- Output uses single-width characters only (ASCII, `█▉▊▋▌▍▎▏░▒▓`, `·`); no emoji. No line is wider than `columns − 1`.
- Colour only on a TTY, and only while `NO_COLOR` is unset or empty. When stdout is not a TTY: no escape codes, just a start line and a summary line.
- Stop keys are `q`, `Q` and Ctrl-C. Ctrl-D is not a stop key.
- Exit codes: 0 when the timer finishes, the user stops it or low battery stops it; 1 for runtime failures; 2 for usage errors.
- `wake/` is its own git repository (branch `main`) nested in the Kjenn checkout and listed in Kjenn's `.git/info/exclude`. Conventional Commits.

## Review Focus

1. **wake dies abruptly** (`kill -9`, a crash, the terminal window closed): caffeinate must exit on its own within a second or two, not keep the Mac awake forever. → Task 6, "caffeinate exits when wake is killed with SIGKILL".
2. **Terminal resized mid-run**, including narrower than the big clock or down to one column: no wrapped or garbled lines; the view drops to one line and comes back when there is room. → Task 5 size sweep; Task 8 "redraws fully after a resize".
3. **The Mac sleeps anyway** (lid closed on battery): on waking, the countdown reflects the time that passed and ends at the end time it showed, not later. → Task 7, "follows the wall clock if the Mac slept anyway".
4. **An error mid-run**: the terminal comes back (alternate screen left, cursor shown, raw mode off) and caffeinate stops. → Task 7, "an error mid-run still stops caffeinate and restores the terminal"; Task 8 raw-mode test.
5. **A Mac without a battery, or `pmset` failing**: the battery guard stays off, nothing crashes, no battery text appears. → Task 3 desktop fixture; Task 7, "runs on a Mac without a battery".

### Task 4: Drawing primitives

**Files:**
- Create: `src/draw.ts`, `test/draw.test.ts`

**Interfaces:**
- Produces:
  - `const GRADIENT: readonly number[] = [57, 63, 69, 75, 81, 87]`: 256-colour codes, violet to cyan
  - `paint(text: string, color: number, enabled: boolean): string`: `\x1b[38;5;<color>m<text>\x1b[0m` when enabled, else `text`
  - `dim(text: string, enabled: boolean): string`: `\x1b[2m<text>\x1b[0m` when enabled, else `text`
  - `stripAnsi(text: string): string`: removes `/\x1b\[[0-9;?]*[A-Za-z]/g`
  - `visibleWidth(text: string): number`: `stripAnsi(text).length`
  - `renderBar(fraction: number, width: number): string`: exactly `width` characters. Clamp `fraction` to 0..1 and take `floor(fraction × width × 8)` eighths: `█` per whole cell, then one partial from `['', '▏', '▎', '▍', '▌', '▋', '▊', '▉'][eighths % 8]` when non-empty, then `░` for the rest
  - `renderSweep(tick: number, width: number): string`: exactly `width` characters of `░`, with the comet `▒▓█▓▒` starting at cell `(tick % (width + 5)) − 5`, clipped at both ends
  - `bigText(text: string): string[]`: 5 rows of equal length, drawn from the font below; each pixel `#` becomes `██` and `.` becomes two spaces; glyphs are separated by two spaces

### Task 5: Frame layout

**Files:**
- Create: `src/frame.ts`, `test/frame.test.ts`

**Interfaces:**
- Consumes: `renderBar`, `renderSweep`, `bigText`, `paint`, `dim`, `GRADIENT`, `stripAnsi`, `visibleWidth` (Task 4)
- Produces:
  - `type View = { clock: string; caption: string; fraction: number | null; tick: number; status: string }`: `fraction` is `null` for open-ended runs
  - `renderFrame(view: View, cols: number, rows: number, color: boolean): string[]`
  - `frameUpdate(prev: string[] | null, next: string[]): string`

Layout rules for `renderFrame`, where `big = bigText(view.clock)` and `bw = big[0].length`:

- **Big layout** when `rows >= 10` and `cols >= bw + 4`. Start with `floor((rows − 10) / 2)` empty lines, then 10 lines, with no blank lines after:
  1. The five `big` rows, each indented `floor((cols − bw) / 2)` spaces. With colour, row `r` is painted `GRADIENT[r]` (the row text, not the indent).
  2. `''`
  3. The caption, cut to `cols − 1` characters and indented `floor((cols − length) / 2)` spaces; dimmed.
  4. `''`
  5. `'  ' + bar`, where bar is `renderSweep(tick, cols − 4)` when `fraction` is `null`, else `renderBar(fraction, cols − 4)`. With colour, filled cells (`█` and the partial) take `GRADIENT[floor(i × GRADIENT.length / (cols − 4))]` for cell `i`, the sweep's comet takes the last gradient colour, and `░` is dimmed.
  6. Bottom line: `left` is `''` when `fraction` is `null`, else `'  ' + floor(fraction × 100) + '%'`. If `left.length + 1 + status.length <= cols − 2`, pad between them so the line is exactly `cols − 2` long with `status` at the end (dimmed); otherwise the line is just `left`.
- **Compact layout** otherwise, one line. `pct` is `''` when `fraction` is `null`, else `' ' + (floor(fraction × 100) + '%').padStart(4)`. `barWidth = cols − 3 − clock.length − pct.length`. When `barWidth >= 1` the line is `' ' + clock + ' ' + bar(barWidth) + pct`. Otherwise it is `(' ' + clock).slice(0, max(0, cols − 1))`.

`frameUpdate`: when `prev` is `null` or has a different length, return `'\x1b[H' + next.map(line => line + '\x1b[K').join('\r\n') + '\x1b[J'`. Otherwise return, for each index `i` whose line changed, `` `\x1b[${i + 1};1H` + next[i] + '\x1b[K' `` concatenated; `''` when nothing changed.

### Task 7: The run loop

**Files:**
- Create: `src/run.ts`, `test/run.test.ts`

**Interfaces:**
- Consumes: `parseArgs`, `HELP` (Task 2); `formatClock`, `formatHuman`, `formatEndTime` (Task 1); `Battery`, `isBatteryLow`, `batteryLabel`, `LOW_BATTERY_PERCENT` (Task 3); `View`, `renderFrame` (Task 5); `KeepAwake` (Task 6)
- Produces:
  - `const TICK_MS = 100`, `const BATTERY_POLL_MS = 30_000`
  - `type StopReason = 'done' | 'stopped' | 'battery' | 'lost'`
  - `type Screen = { color: boolean; size(): { cols: number; rows: number }; enter(): void; draw(lines: string[]): void; leave(): void }`
  - ```ts
    type Deps = {
      platform: string;                                   // process.platform
      now: () => number;                                  // wall clock, ms
      wait: (ms: number) => Promise<void>;
      readBattery: () => Promise<Battery | null>;
      keepAwake: () => KeepAwake;                         // starts caffeinate; may throw
      screen: Screen | null;                              // null when stdout is not a TTY
      print: (line: string) => void;                      // stdout; adds the newline
      printError: (line: string) => void;                 // stderr; adds the newline
      onStopRequest: (handler: () => void) => () => void; // returns unsubscribe
    };
    ```
  - `buildView(now: number, start: number, end: number | null, tick: number, battery: Battery | null): View`
  - `run(argv: string[], deps: Deps): Promise<number>`: resolves to the exit code

`run`, in this order:

1. `parseArgs(argv)`. Help → `print(HELP)`, return 0. Error → `printError(message)`, return 2.
2. `platform !== 'darwin'` → `printError('wake: needs macOS (it uses caffeinate).')`, return 1.
3. `battery = await readBattery()`. If `isBatteryLow(battery)` → `` printError(`wake: battery is at ${percent}%. Plug in to keep this Mac awake.`) ``, return 1.
4. `keeper = keepAwake()`. If it throws → `` printError(`wake: could not start caffeinate: ${error.message}`) ``, return 1.
5. `start = now()`; `end = durationMs === null ? null : start + durationMs`; register `onStopRequest`, which sets a stop flag.
6. With a screen, `screen.enter()`. Without one, `print` the start message:
   - timed: `` `wake: keeping this Mac awake for ${formatHuman(durationMs / 1000)}, until ${formatEndTime(end, start)}. Press Ctrl-C to stop.` ``
   - open-ended: `` `wake: keeping this Mac awake until you stop it or the battery drops to ${LOW_BATTERY_PERCENT}%. Press Ctrl-C to stop.` ``
7. In `try`, loop with `tick = 0` and `lastPoll = start`: `t = now()`. The reason is the first that applies: stop flag → `stopped`; `!keeper.alive()` → `lost`; `end !== null && t >= end` → `done`; `t − lastPoll >= BATTERY_POLL_MS` → read the battery again, set `lastPoll = t`, and give `battery` if it is low. With a reason, leave the loop. Otherwise, with a screen, draw `renderFrame(buildView(t, start, end, tick, battery), cols, rows, screen.color)`; then `tick += 1` and `await wait(TICK_MS)`. In `finally`: `keeper.stop()`, `unsubscribe()`, `screen?.leave()`, in that order.
8. `elapsed = formatHuman((now() − start) / 1000)`, then the summary:
   - done: `` `wake: done after ${elapsed}. Your Mac can sleep again.` ``
   - stopped: `` `wake: stopped after ${elapsed}. Your Mac can sleep again.` ``
   - battery: `` `wake: battery at ${percent}%, stopped after ${elapsed}. Your Mac can sleep again.` ``
   - lost: `` `wake: caffeinate quit unexpectedly after ${elapsed}. Your Mac can sleep again.` `` via `printError`, return 1. The other three use `print` and return 0.

`buildView`, for a timer: clock `formatClock(ceil(max(0, end − now) / 1000))`, caption `` `left · until ${formatEndTime(end, now)}` ``, fraction `(now − start) / (end − start)` clamped to 0..1. Open-ended: clock `formatClock(floor((now − start) / 1000))`, caption `awake · until you stop it`, fraction `null`. Status is `[batteryLabel(battery), 'q to stop']` with empty parts dropped, joined by `' · '`.

```ts
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { spawn, spawnSync } from 'node:child_process';
import { mkdtempSync, readFileSync } from 'node:fs';
import { tmpdir } from 'node:os';
import { join } from 'node:path';
import { fileURLToPath } from 'node:url';
import { displaySleepBlockedFor, waitFor } from './helpers.ts';

const BIN = fileURLToPath(new URL('../bin/wake.js', import.meta.url));
const mac = { skip: process.platform !== 'darwin' };

function start(args: string[]) {
  const child = spawn(process.execPath, [BIN, ...args], { stdio: ['ignore', 'pipe', 'pipe'] });
  let stdout = '';
  child.stdout.on('data', (chunk) => { stdout += chunk; });
  const exited = new Promise<number | null>((resolve) => child.on('exit', resolve));
  return { child, exited, stdout: () => stdout };
}

test('--help prints usage', () => {
  const result = spawnSync(process.execPath, [BIN, '--help'], { encoding: 'utf8' });
  assert.equal(result.status, 0);
  assert.match(result.stdout, /^Usage: wake \[duration\]\n/);
});

test('a bad duration exits 2', () => {
  const result = spawnSync(process.execPath, [BIN, '3x'], { encoding: 'utf8' });
  assert.equal(result.status, 2);
  assert.equal(result.stderr, 'wake: "3x" is not a duration. Try 30s, 5m, 2h or 1h30m.\n');
});

test('a 2s timer holds the display awake, then lets go', mac, async () => {
  const w = start(['2s']);
  assert.ok(await waitFor(() => displaySleepBlockedFor(w.child.pid!), 1_500));
  assert.equal(await w.exited, 0);
  const lines = w.stdout().trimEnd().split('\n');
  assert.match(lines[0], /^wake: keeping this Mac awake for 2s, until (\w{3} )?\d\d:\d\d\. Press Ctrl-C to stop\.$/);
  assert.equal(lines[1], 'wake: done after 2s. Your Mac can sleep again.');
  assert.ok(await waitFor(() => !displaySleepBlockedFor(w.child.pid!), 2_000));
});

test('SIGINT stops an open-ended run', mac, async () => {
  const w = start([]);
  assert.ok(await waitFor(() => w.stdout().includes('keeping this Mac awake'), 2_000));
  w.child.kill('SIGINT');
  assert.equal(await w.exited, 0);
  assert.match(w.stdout(), /wake: stopped after \d+s\. Your Mac can sleep again\.\n$/);
  assert.ok(await waitFor(() => !displaySleepBlockedFor(w.child.pid!), 2_000));
});

test('on a terminal it draws on the alternate screen and restores it', mac, () => {
  const file = join(mkdtempSync(join(tmpdir(), 'wake-')), 'pty.out');
  const result = spawnSync('script', ['-q', file, process.execPath, BIN, '2s'], { stdio: 'ignore', timeout: 10_000 });
  assert.equal(result.status, 0);
  const log = readFileSync(file, 'utf8');
  const entered = log.indexOf('\x1b[?1049h');
  const left = log.lastIndexOf('\x1b[?1049l');
  assert.ok(entered >= 0 && left > entered, 'entered and left the alternate screen');
  assert.ok(log.lastIndexOf('\x1b[?25h') > entered, 'cursor shown again');
  assert.ok(log.indexOf('wake: done after 2s.') > left, 'summary printed after leaving');
});
